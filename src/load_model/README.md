# 📂 Load Model

Testverzeichnis zur Fehleranalyse beim Laden gespeicherter PyTorch-Modelle.

## Inhalte

- `load_model.py`: Läd ein Modell aus `.pth` oder `.pt` und überprüft dessen Funktionsfähigkeit (z. B. Vorwärtsdurchlauf, Gerätekompatibilität, Klassenausgabe).

Nützlich zur Validierung von gespeicherten Trainingsartefakten und Debugging bei Ladeproblemen.
